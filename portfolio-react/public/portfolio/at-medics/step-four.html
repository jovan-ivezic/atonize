Step 4. Implementation

Successfully embedding a new way of working relies on a good implementation strategy. The new model will change the manner in which individuals will work, including renewing processes and policies. The implementation must address how to safely move from the way it is to the way it needs to be. The change is not stand-alone, it needs to be reinstalled into an existing culture and system. The implementation plan guides you through all the steps that will allow the change to be introduced and sustained over time.
